# 開發需求說明書：即時觀看網路攝影機影片和聲音。

你是一個資深的 python 開發專家。請根據以下規格，為專案開發一個名為 `mplusVideo_Viewer_2025.py` 的程式。

## 1. 執行環境與開發規範（硬性約束）

* **檔案名稱**：`mplusVideo_Viewer_2025.py`
* **執行模式**：在 CLI 執行 python mplusVideo_Viewer_2025.py 指令
* **架構限制（極重要）**：
  * 必須嚴格遵循專案既有的 `@Specification.md` 規格。
  * **禁止使用全域變數** (`global`)。
  * **禁止使用相依性注入** (Dependency Injection)。

## 2. 核心功能與資料邏輯
* 負責即時觀看網路攝影機影片和聲音。
* 虛擬區域縮放引擎、智能音訊管理機制，以及一個滑鼠懸浮控制面板。使用者可以在任何畫面上點擊並拖曳出一個矩形框進行放大（即使在全螢幕模式下也能正常操作）。
* 使用 python-mpv
* 讀取在同一資料夾的 viewer_config.json 是否存在。如果沒有展出對白匣，展出視窗請求用戶輸入六個 RTSP URL 輸入匣，最少輸入一個 RTSP URL，和正確的 RTSP URL 格式。請確定防止注射攻擊。
* **  然後儲存 viewer_config.json 。
* **  如果有 viewer_config.json 讀取內容。

### 2.1 介面
* 默認值是 width: 1280px, height: 720px
* 畫面可以用滑鼠拖曳放大縮小，但不能小過默認值 。也可以用 menu bar to minimize, and maximize or full screen.
* 左邊有窄菜單，選擇為 1, 2, 4, and 6 用圖示代表。
* 意思為主畫面有多少影片在播放。
* 播放影片匣必須是 16:9 比例，和有控制聲音拖曳棒、靜音按鈕、大小縮放的按鈕和 1:1 還原按鈕。
* 控制聲音拖曳棒和靜音按鈕必須是互動的。
* 點擊大小縮放的按鈕後用戶可以用滑鼠描繪正方形箱以放大那區域。也可以用滑鼠上的輪控制大小縮放。
* **自動互鎖音訊邏輯 (Audio Interlocking)：**
  * 切換到 **1 畫面** 時：第 1 路聲音會自動開啟。
  * 切換到 **2、4、6 畫面** 時：所有串流初始均為**靜音**狀態（避免多個音軌同時播放造成混亂）。
  * **如何聽取聲音？** 在任何畫面上**滑鼠左鍵連點兩下**，即可立即獨佔啟用該畫面的聲音，此時該畫面會亮起**綠色邊框**作為視覺提示，其他畫面則自動被切換為靜音。
* **滑鼠框選縮放 (Click-to-Zoom)：**
  * 在任何畫面上**按住左鍵並拖曳**出一個矩形，放開後，底層 MPV 硬體解碼器會立即將該區域局部放大填滿整個格子。
  * **無限次連續調整：** 放大後你仍然可以在畫面上繼續畫框進一步放大，或調整不同的局部區域。
  * **一鍵還原：** 在畫面上點擊**滑鼠右鍵**，畫面會瞬間重設回原來的 100% 完整視角。
* **全螢幕優化與懸浮控制 (HUD)：**
  * 點擊右上角的「🖥️ 全螢幕放大所選」後，系統會將當前亮綠框（有聲音）的畫面放大至整個螢幕。
  * 進入全螢幕後，螢幕上方中央會自動掉下一個深色半透明的**懸浮控制面板**。即使在全螢幕下，你**依然可以用滑鼠左鍵畫框縮放畫面、用右鍵重設**，並可以隨時透過面板切換聲音或一鍵點擊退出全螢幕。
